# Repository instructions

Use the Sloar Chat Coder protocol for repository work.

Before modifying this repository:
1. Recover the exact durable repository state and current HEAD/tree when available.
2. Inspect the capabilities actually available in the current session; do not assume GitHub/CI/deployment write access.
3. Prefer local/sandbox implementation and verification, then publish through the lowest sufficient authorized capability.
4. Revalidate the remote base immediately before publication.
5. Do not claim tests, deployment, Instagram publication, or other remote behavior without evidence.

Upstream protocol: https://github.com/hoonex/sloar-chat-coder
